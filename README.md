# Blamo Watkins | Web Design Portfolio

My portfolio presents projects from GIT 215 at Arizona State University. It includes my background in Graphic Information Technology and two examples of how I organize content and build responsive websites.

**[View the live portfolio](https://blamowatkins.github.io/portfolio/)**

## Pages

- [Home](https://blamowatkins.github.io/portfolio/) introduces my work and areas of focus.
- [About](https://blamowatkins.github.io/portfolio/about.html) covers my education, skills, and tools.
- [Projects](https://blamowatkins.github.io/portfolio/projects.html) includes screenshots, what I built, and links to the live sites and source code.
- [Contact](https://blamowatkins.github.io/portfolio/contact.html) links to my GitHub and CodePen profiles.

## Featured projects

- **Watkins Bros Detailing.** A responsive mobile auto detailing site with service pricing, before-and-after photos, and a booking request form. [Live site](https://blamowatkins.github.io/WATKINS-4-build/) · [Source](https://github.com/blamowatkins/WATKINS-4-build)
- **Copper City Makerspace.** A multi-page course code-along about workshops, tools, and membership. I organized and linked the pages using a shared course stylesheet by Christina Carrasquilla. [Live site](https://blamowatkins.github.io/5-Code-Along/) · [Source](https://github.com/blamowatkins/5-Code-Along)

## Built with

Semantic HTML, CSS Grid and Flexbox, and GitHub Pages. The four pages use a shared stylesheet for typography, spacing, and responsive layouts.

## Preview locally

Clone or download this repository, then open `index.html` in a browser. The site has no build step or dependencies.
